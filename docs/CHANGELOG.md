## 2026-10-19 — 復健與護眼專區 UI

### 新增內容
- 挑戰頁標題下新增「復健與護眼」入口，進入獨立頁面。

- CDR（頸椎人工椎間盤置換術）術後：術後保護、日常活動恢復衛教及回診詢問清單。

### 修改範圍
- 既有 ChallengeFragment、fragment_challenge.xml、nav_graph.xml 僅新增入口及導覽。
- 其餘為新增專區程式與資源；保留既有掃描、監控、孵蛋、晴金龍動畫、故事、寵物、商店及每日任務。
