Demo 功能

HeadUp demo 聚焦在前鏡頭姿勢偵測、背景守護、資料統計與遊戲化任務，適合展示產品原型與評審體驗。

01

即時姿勢偵測

前鏡頭辨識眼睛、鼻子、肩膀等點位，推估頭前傾與頸部姿勢狀態。

02

AI 預警

加入 EMA 降噪、3 秒防抖與角速度追蹤，降低誤觸提醒並提前攔截姿勢崩塌。

03

家長資料圖表

將真實紀錄同步到後端，透過 dashboard 查看用戶、訪客與每日姿勢統計。

04

Vision Dragon

以 Q 版 Vision Dragon、任務和獎勵提升學生持續使用動機。

Android 安裝方式

Demo APK 不走 Play Store 時，手機會要求允許瀏覽器安裝未知來源應用程式。

1

開啟網站

用 Android 手機開啟 GitHub Pages 介紹頁，點擊下載 Demo。

2

允許安裝

依照系統提示允許瀏覽器安裝未知來源 APK。

3

開始體驗

開啟 HeadUp，使用訪客模式或註冊帳號體驗姿勢防護流程。
